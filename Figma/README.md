# Figma Mobile UI — الخطة 1 (MVP Marketplace — 20 شاشة متكاملة)

واجهات وتصميمات عالية الجودة (High-Fidelity) متوافقة كلياً مع Figma ومبنية وفق متطلبات **الخطة 1: النسخة الأساسية (MVP Marketplace)** بنفس نظام التصميم، الهوية البصرية، وتدرجات النيلي الملكي.

---

## 📱 قائمة الشاشات الكاملة (20 شاشة مصممة)

### 🔐 أولاً: التسجيل والمصادقة وبدء الاستخدام (Auth & Onboarding)
1. **`01-login.svg` — تسجيل الدخول:**
   - شريط حالة احترافي مع Dynamic Island.
   - شعار المنصة وتدرجات نيلية فاخرة.
   - حقول إدخال ذكية مع أيقونات الهوية والأمان وزر Google الرسمي.
2. **`02-signup.svg` — إنشاء حساب جديد:**
   - مؤشر خطوات تفاعلي (الخطوة 1 من 3).
   - اختيار وسيلة التسجيل (هاتف أو بريد إلكتروني أو Google أو Apple)، الدولة، المحافظة، كلمة المرور وتأكيدها.
3. **`03-verify-otp.svg` — تأكيد رمز التحقق (OTP):**
   - درع أمان رقمي بتدرج مشفر، خانات إدخال أرقام، ومؤقت إعادة إرسال مع توضيح وسيلة الاستلام المختارة، بما فيها Google وApple.
4. **`04-account-type.svg` — اختيار نوع الحساب:**
   - بطاقتان تفاعليتان للمقارنة: حساب مستخدم vs حساب متجر مع تنبيه مراجعة الإدارة.
5. **`05-profile-setup.svg` — بيانات المستخدم الشخصية:**
   - رافع الصورة الرمزية، الاسم، والعنوان النصي.
6. **`06-distributor-setup.svg` — إعداد المتجر:**
   - اسم المتجر، الصورة، العنوان النصي، الغلاف، والأقسام الأساسية (إلكترونيات / ملابس / إكسسوارات / عربيات).
   - توضيح أن الأقسام الفرعية تظهر عند إضافة المنتج تحت القسم الأساسي.
7. **`07-forgot-password.svg` — استعادة كلمة المرور:**
   - إدخال الهاتف أو البريد المسجل لاستلام رمز التحقق الفوري مع إرشادات الأمان.

---

### 🛍️ ثانياً: رحلة المشتري والماركت بليس (Shopper Experience)
8. **`08-marketplace-home.svg` — الواجهة الرئيسية للماركت بليس:**
   - هيدر التوصيل حسب الموقع الجغرافي والإشعارات، شريط بحث وفلاتر.
   - مساحة إعلانية ممولة وواضحة (Sponsored Ad Banner) وفق الخطة 1.
   - قسمي الملابس والإلكترونيات، بطاقات منتجات مميزة، وشريط تنقل سفلي عائم (Dock).
9. **`09-product-details.svg` — تفاصيل المنتج والمواصفات:**
   - معرض صور للمنتج مع مؤشر السلايدر، شارة الموزع المعتمد وزر التواصل.
   - محدد المقاسات (S, M, L, XL, XXL) والألوان، وحساب نسبة التوفير والخصم.
   - مواصفات الخامة والضمان وزر تقديم بلاغ ضد منتج مخالف.
10. **`10-search-filters.svg` — البحث المتقدم وتصفية النتائج:**
    - فلترة حسب القسمين الأساسيين (الملابس / الإلكترونيات).
    - شارات الفرز السريع (الموزعون المعتمدون فقط، الخصومات، التقييم 4.5+).
11. **`11-multi-vendor-cart.svg` — السلة المقسمة تلقائياً حسب الموزع:**
    - تجسيد لمتطلب الخطة 1 الجوهري: تقسيم سلة المشتريات تلقائياً حسب الموزع لاختلاف مدة وتكلفة الشحن وسياسة الاسترجاع (شحنة ملابس + شحنة إلكترونيات).
12. **`12-checkout-payment.svg` — إتمام الطلب وبوابات الدفع:**
    - تطبيق بوابات الدفع المحددة بالخطة 1:
      - **Paymob:** المحافظ الإلكترونية (Vodafone Cash, Orange Cash, e& money, WE Pay) والكروت البنكية.
      - **FawryPay:** الدفع من منافذ فوري بكود مرجعي.
      - **الدفع عند الاستلام (COD).**
      - **InstaPay:** تحويل يدوي مؤقت لحساب تجاري معتمد مع إرفاق الإيصال.
13. **`13-order-tracking.svg` — متابعة دورة وحالات الطلب:**
    - خط زمني متكامل يجسد حالات الخطة 1 التسعة: (جديد ⬅️ انتظار التأكيد ⬅️ مؤكد ⬅️ قيد التجهيز ⬅️ قيد التوصيل ⬅️ مكتمل / ملغي / مرفوض / مرتجع).
    - بيانات الموزع وكابتن الشحن مع أزرار التواصل والإلغاء.
14. **`14-distributor-storefront.svg` — واجهة متجر الموزع للمشترين:**
    - غلاف وشعار المتجر، شارة الاعتماد الإداري، تقييمات المشترين، سرعة الرد، عروض المتجر، والكتالوج الكامل.
15. **`15-chat-conversation.svg` — الدردشة والتواصل المباشر:**
    - محادثة حية بين المشتري والموزع، عرض بطاقة المنتج محل الاستفسار أعلى الشاشة، وتنبيه الأمان المالي.
16. **`16-reviews-and-report.svg` — التقييمات والبلاغات الرسمية:**
    - نموذج تقييم بالنجوم وجودة التغليف والتوصيل، وتبويب لتقديم بلاغ رسمي لإدارة المنصة للتحقيق وفض النزاع.

### 💼 ثالثاً: بوابة الموزع المعتمد (Distributor Portal)
17. **`17-distributor-dashboard.svg` — لوحة تحكم الموزع والأرباح:**
    - بطاقة صافي الأرباح المتاحة للسحب (بعد خصم عمولة المنصة) مع زر طلب السحب.
    - مؤشرات الطلبات النشطة، المنتجات المعروضة، ونقرات الإعلانات الممولة.
    - قائمة الطلبات الواردة التي تتطلب إجراء (تأكيد أو تسليم للشحن).
18. **`18-add-product.svg` — إضافة وتعديل منتج جديد:**
    - رافع الصور المتعددة، اختيار القسم (ملابس أو إلكترونيات)، السعر والخصم، المخزون المتاح، وتنبيه مراجعة الإدارة.
19. **`19-distributor-ads.svg` — إدارة الحملات الإعلانية الممولة:**
    - تطبيق نموذج إعلانات الخطة 1: تحديد مكان الظهور (الرئيسية أو القسم)، العنوان، الميزانية اليومية، المدة، والاستهداف الجغرافي.
    - تقرير إحصائي مباشر: عدد المشاهدات، النقرات، والطلبات الناتجة.

### ⚖️ رابعاً: لوحة الإدارة والاعتمادات (Admin Moderation)
20. **`20-admin-approvals.svg` — لوحة الإدارة ومراجعة الاعتمادات:**
    - اعتماد طلبات الموزعين المعلقين (فحص السجل التجاري والنطاق الجغرافي قبل التفعيل).
    - مراجعة المنتجات الجديدة واعتماد الإعلانات الممولة.
    - إدارة وفض الشكاوى والبلاغات المقدمة من المشترين ضد أي مخالفات.

## 🎨 المواصفات الفنية ونظام التصميم (Design System)

- **الأبعاد القياسية:** `393 × 852 px` (معيار iPhone 15/16 Pro القياسي في Figma).
- **الاتجاه واللغة:** دعم كامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`).
- **الخطوط المدمجة:** `Cairo` للنصوص العربية و `Plus Jakarta Sans` للأرقام والأكواد الإنجليزية.
- **لوحة الألوان الأساسية:**
  - `Primary Blue`: `#2563EB` إلى `#1D4ED8`
  - `Light Blue Tint`: `#EFF6FF` / `#DBEAFE`
  - `Background`: `#F8FAFC` مع طبقات `#FFFFFF`
  - `Text Headings`: `#0F172A`
  - `Text Body & Muted`: `#475569` / `#64748B` / `#94A3B8`
  - `Accents`: `#10B981` (نجاح واعتماد)، `#F59E0B` (قيد المراجعة وتنبيه)، `#EF4444` (بلاغات وإلغاء وحذف)

## 🚀 كيفية الاستعراض والاستيراد إلى Figma

### 1. الاستعراض التفاعلي عبر المتصفح:
افتح ملف **`preview.html`** في أي متصفح ويب:
- **محاكي هاتف تفاعلي:** تنقل بين الـ 20 شاشة مع تفاصيل ووصف كل واجهة وزر تنزيل فوري.
- **فلاتر التصنيف:** تصفية فورية حسب الدور (كافة الشاشات، المصادقة، رحلة المشتري، بوابة الموزع، لوحة الإدارة).
- **عرض الشبكة الكاملة (Grid View):** استعراض كافة الشاشات جنباً إلى جنب مع إمكانية القفز السريع للمحاكي وتنزيل الـ SVG.

### 2. الاستيراد المباشر إلى Figma:
- اسحب أي ملف SVG من المجلد (`01-login.svg` حتى `20-admin-approvals.svg`) وأفلته مباشرة داخل مساحة العمل في برنامج أو موقع **Figma**.
- ستظهر الواجهات كـ Vector Frames نقية قابلة للتعديل والتحريك مع الاحتفاظ التام بالنصوص، والألوان، والأبعاد.
