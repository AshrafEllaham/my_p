# دليل نقل واستيراد تصميم منصة سعي إلى Google Stitch

هذه الحزمة مجهزة بالكامل لربط واستيراد نظام وتصميم منصة **سعي** داخل **Google Stitch** (`https://stitch.withgoogle.com`).

---

## محتويات الحزمة

1. **`DESIGN.md`**:
   - مواصفات نظام التصميم القياسي الصادر من Google Labs (`@google/design.md`).
   - يتضمن Front Matter لـ Design Tokens (ألوان أسود سعي `#000000`، خطوط Cairo وInter، مقاسات الهاتف `440x956`، أنصاف الأقطار، والظلال).
   - تم اختباره واعتماده عبر Linter الرسمي وحقق: **0 أخطاء و 0 تحذيرات** مع الامتثال لمعايير WCAG AA.

2. **مجلد `screens/`**:
   - يحتوي على **31 شاشة تفاعلية كاملة** تغطي رحلة المستخدم ورحلة المتجر/الموزع.
   - جميع الشاشات مصممة بصيغة **Self-contained HTML** (أي مدمج بداخلها كود الـ CSS والخطوط والأيقونات بالكامل)، مما يجعلها تعمل في أي متصفح أو عند سحبها إلى Google Stitch كـ Screen Prototypes دون فقدان التنسيقات.

3. **`stitch-manifest.json`**:
   - بيان برمجي لجميع الشاشات ونظام التصميم للمزامنة المباشرة عبر `@google/stitch-sdk`.

---

## خطوات الاستيراد إلى Google Stitch

### الطريقة الأولى: استيراد نظام التصميم عبر واجهة Stitch (الأسهل والمباشرة)
1. افتح مشروعك في **Google Stitch** على [stitch.withgoogle.com](https://stitch.withgoogle.com).
2. من القائمة الجانبية أو الإعدادات، انتقل إلى:
   `Settings` ➔ `Design System` ➔ `Import DESIGN.md`.
3. اختر ملف [`DESIGN.md`](./DESIGN.md) المرفق في هذه الحزمة.
4. سيتعرف Stitch فوراً على لوحة ألوان سعي، الخطوط العربية والإنجليزية، مقاسات الشاشات، والمكونات القياسية.

### الطريقة الثانية: رفع الشاشات كـ Prototypes أو مراجع (Screens / Mockups)
1. داخل الـ Canvas في Stitch، يمكنك رفع أي شاشة من مجلد [`screens/`](./screens/) (مثل `08-user-home.html` للرئيسية، أو `12-product-details.html` للشراء، أو `17-distributor-dashboard.html` للمتجر).
2. نظراً لأن الشاشات مدمجة ومستقلة، سيقوم Stitch بقراءة هيكل الـ DOM وتطبيق القواعد عليها، ويمكنك استخدام الأوامر النصية لتوليد شاشات جديدة متوافقة معها بدقة.

### الطريقة الثالثة: المزامنة البرمجية عبر `@google/stitch-sdk`
إذا كان لديك مفتاح API (`STITCH_API_KEY`) ومعرف مشروع:
```bash
npm install @google/stitch-sdk
```
يمكنك رفع وتحديث الشاشات من الكود مباشرة عبر الـ SDK.
